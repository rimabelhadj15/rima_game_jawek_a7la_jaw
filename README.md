# Chkoba - Tunisian Card Games (Local Hotspot Multiplayer)

This folder contains the Dart/Flutter source code (`lib/` + `pubspec.yaml`)
for the game. It does **not** yet include the native `android/` project files,
because those need to be generated by your local Flutter SDK.

## One-time setup (do this once, in this exact order)

1. Open a terminal **inside this folder** (`chkoba_app/`).
2. Generate the missing native scaffolding without touching the code you already have:
   ```
   flutter create --platforms=android --org com.yourname .
   ```
   This adds `android/` (and a placeholder `lib/main.dart`, `test/`, etc.)
   without deleting the rest of your project.
3. Since step 2 overwrites `lib/main.dart` and `pubspec.yaml` with Flutter's
   default template, **re-copy the real ones back in** from this delivered
   folder if they got replaced (check `git status` or just diff — usually
   `flutter create` on an existing folder only adds missing files and leaves
   yours alone, but double check `lib/main.dart` still has `ChkobaApp` in it).
4. Open `android/app/src/main/AndroidManifest.xml` and make sure these
   permissions are present inside `<manifest>` (above `<application>`):
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   <uses-permission android:name="android.permission.ACCESS_WIFI_STATE"/>
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
   ```
5. Install dependencies:
   ```
   flutter pub get
   ```

## Build the APK

```
flutter build apk --release
```

The APK will be at `build/app/outputs/flutter-apk/app-release.apk`.

## How to actually play

1. **Host**: Settings > Hotspot > turn it on. Open the app > "Host a Game" >
   enter your name > "Start Server". The app shows an IP address (usually
   `192.168.43.1`) — tell it to the other players out loud.
2. **Everyone else**: connect their phone's WiFi to the host's hotspot
   (normal Android WiFi settings, using the hotspot name/password shown on
   the host phone). Then open the app > "Join a Game" > enter name + the IP
   address the host gave you > "Connect".
3. Once 2-4 players are in the lobby, the host taps "Start Game".

## Project layout

```
lib/
├── main.dart
├── core/            # networking, lobby, theme - reusable for future games
└── games/chkoba/    # Chkoba-specific rules, state, and UI
```

To add a second Tunisian game later, drop a new folder next to `games/chkoba/`
following the same models/logic/providers/ui structure, and add a game picker
screen before the lobby.

## Known limitations to test carefully

- Host IP detection lists all local IPv4 addresses; on some Android versions
  the hotspot address may not be the first one shown — if joining fails, try
  the other addresses listed, or check Settings > Hotspot > Connected devices
  for the host's own IP.
- Disconnect/reconnect currently pauses only in the sense that the host keeps
  the game state and will resume broadcasting to a player once their app
  reconnects and re-joins with a new WebSocket — reconnecting into the *same*
  seat (not a new player slot) is a good next improvement.
